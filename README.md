# 📊 E-commerce Sales Dashboard | Excel

## 📌 Project Overview

An interactive Excel dashboard developed to analyze e-commerce sales
performance, profitability, customer behavior, and product trends.

This project demonstrates practical data cleaning, analysis, visualization,
and dashboard-building skills using Microsoft Excel.

## 🎯 Business Questions

- What are the total sales and profit?
- Which products generate the highest sales?
- Which categories perform best?
- Which regions generate the most revenue?
- Who are the top customers?
- How do sales change over time?
- How does sales performance compare with targets?
- Which payment methods are most commonly used?
- What is the overall profit margin?

## 🛠️ Tools & Skills

- Microsoft Excel
- Data Cleaning
- XLOOKUP
- SUMIFS
- COUNTIFS
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
- KPI Analysis
- Dashboard Design
